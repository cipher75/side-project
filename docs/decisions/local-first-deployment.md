# 로컬 우선 배포

## Decisions

- 웹서비스는 사용자의 PC에서 `localhost`로만 동작합니다. 계정과 로그인은 두지 않습니다.
- Claude Code와 데스크톱 앱의 hook은 같은 PC의 이 웹서비스로 활동 정보를 보냅니다.
- 활동 정보는 외부 서버로 보내거나 저장하지 않습니다.

## Boundaries

- 다른 기기(모바일 등)에서 화면을 보는 기능을 허용하지 않는다는 뜻이 아니라, 아직 범위에 넣지 않았다는 결정입니다.
- 허용 처리는 계속 Claude Code, 데스크톱 앱, 모바일에서 하며, 웹 화면은 처리 기능을 갖지 않습니다.

## Why

말풍선에는 실행한 명령이나 파일 경로 같은 tool 입력이 표시될 수 있습니다. 이 정보를 외부 서버로 보내면 개인정보 문제가 생기고 인증이 필요해집니다. 로컬에서는 "작업 지시, 사무실 화면 확인, 허용 대기 확인"이라는 핵심 흐름을 가장 작게 검증할 수 있습니다.

## Reconsider when

- 사무실 화면을 PC 밖의 다른 기기에서 봐야 한다는 필요가 반복해서 확인될 때
- 여러 사람이 한 화면을 공유해야 하는 사용 사례가 생길 때

## Still-rejected alternatives

- 처음부터 호스팅된 웹서비스로 제공 — 작업 내용 유출 위험과 인증 비용이 핵심 흐름 검증보다 먼저 생깁니다. 다른 기기 조회가 반복적으로 필요해지면 다시 검토합니다.
