# 로컬 우선 배포와 개인용 호스팅

## Decisions

- 수집과 판정은 PC의 로컬 서버가 맡습니다. hook은 `127.0.0.1`의 로컬 서버로만 보내고, 로컬 서버가 transcript를 읽어 허용 결과를 확정합니다. 로컬 화면은 모든 라벨을 그대로 보여줍니다.
- 다른 기기(모바일 등)에서 보려면 로컬 서버가 줄인 상태만 Vercel에 올린 호스팅 화면으로 전달합니다. 호스팅 화면은 같은 사무실 장면을 읽기 전용으로 보여줍니다.
- 호스팅은 개인용입니다. 계정과 로그인은 두지 않고 토큰으로만 접근하며, 보내는 쪽(PC)의 토큰과 보는 쪽(기기)의 토큰을 따로 둡니다.
- PC를 떠나는 내용은 호출의 상태와 종류, 도구 이름, 파일 이름, skill과 sub-agent 이름, 세션 이름뿐입니다. 명령 내용, URL, 검색어, 프롬프트, 전체 경로, transcript 내용은 보내지 않습니다.
- 호스팅은 Vercel이고, GitHub 저장소와 연결해 배포합니다.

## Boundaries

- 여러 사람이 공유하거나 사용자별 계정이 있는 서비스를 허용하는 결정이 아닙니다.
- hook이 호스팅 주소로 직접 전송하는 경로는 두지 않습니다.
- 호스팅 화면에서 허용이나 거절을 처리하지 않습니다. 이 화면은 보기 전용입니다.
- 호스팅에서 상태를 어디에 저장하고 어떻게 갱신하는지는 정하지 않았습니다. 구현을 정할 때 이 결정의 "보내는 내용" 경계 안에서 고릅니다.
- 로컬 서버가 상태를 파일로 남기지 않는다는 기존 방침은 그대로입니다. 호스팅에 올라가는 줄인 상태는 이 경계의 예외가 아니라 별도의 호스팅 저장입니다.

## Why

말풍선에는 실행한 명령과 파일 경로 같은 도구 입력이 보일 수 있고, 한번 외부 서버로 나간 내용은 되돌릴 수 없습니다. 그래서 무엇을 PC 밖으로 보낼지를 로컬 서버 한 곳에서 거릅니다. 허용 결과(거절됨, 중단됨, 허용됨)와 백그라운드 sub-agent 종료는 PC의 transcript에서만 알 수 있어서, 이를 읽는 로컬 서버가 호스팅 화면의 앞단이 되어야 이 신호를 잃지 않습니다. 허용 창이 뜨고 일이 도는 곳은 어차피 켜져 있는 PC라서, 중계는 새로운 가용성 제약을 만들지 않습니다.

개인용(토큰 하나, 계정 없음)은 모바일에서 허용 대기를 놓치지 않는다는 원래 필요를 가장 작게 채우는 범위입니다.

## Reconsider when

- 여러 사람이 각자 로그인해 보는 서비스가 필요할 때
- 호스팅 화면에서 도구 이름과 파일 이름 이상의 내용이 필요하다는 요구가 반복될 때
- Claude Code가 거절과 종료를 hook으로 직접 알려 주어 transcript와 PC 중계가 필요 없어질 때

## Still-rejected alternatives

- hook이 호스팅 주소로 직접 전송 — 거절됨, 중단됨, 허용됨 구분과 백그라운드 sub-agent 퇴근을 호스팅 화면에서 잃고, 토큰이 hook 설정에 들어갑니다. hook이 이 신호를 직접 제공하면 다시 검토합니다.
- 처음부터 여러 사용자용 서비스 — 계정, 사용자별 데이터 분리, 개인정보 책임이 한꺼번에 생깁니다. 개인용이 검증된 뒤에 검토합니다.
- 명령 내용까지 호스팅으로 전송 — 토큰이나 비밀번호가 명령에 섞일 수 있습니다. 요구가 반복되면 마스킹 방식과 함께 다시 검토합니다.

## Evidence worth preserving

- Vercel 공식 문서(`vercel.com/docs/agent-resources/skills.md`, `.../vercel-plugin.md`, `vercel.com/llms.txt`)를 확인했습니다. 개별 설치되는 공식 스킬 `vercel-cli`는 `vercel/vercel` 저장소에서 설치했습니다.
- Vercel 플러그인(`npx plugins add vercel/vercel-plugin`)은 스킬 33개, 에이전트 3개, hook, 일별 사용 통계를 함께 넣는 넓은 설치라서 설치하지 않았습니다. 저장소 선택 지침(`vercel-storage`: Blob, Upstash Redis 등)은 이 플러그인 안에만 있어서, 저장소를 고를 때 필요하면 그때 설치를 따로 정합니다.
- 최신 문서는 `AGENTS.md`의 안내대로 `vercel.com/llms.txt`를 작업 시작 때 가져옵니다.
