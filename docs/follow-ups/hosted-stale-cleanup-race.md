# 호스팅의 오래된 PC 정리가 새 상태를 지울 수 있음

## 증상
6시간 넘게 소식이 없던 PC가 다시 켜져 상태를 올리는 순간, 기기의 조회가 이전 값을 읽고 정리 대상으로 판단해 HDEL을 보내면 방금 저장된 새 상태가 지워질 수 있다. 그 PC는 다음 살아 있음 신호(최대 60초)까지 호스팅 화면에서 사라진다.

## 증거
`features/office-activity/hosted/handlers.ts`의 `state`가 읽기와 지우기를 따로 보낸다. 코드 리뷰(`code-review low`)가 지적했고, 재현하지는 않았다. 두 요청이 같은 순간에 겹쳐야 생기고 다음 신호에 스스로 복구된다.

## 추정 원인
읽은 값이 오래되었다는 판단과 지우기 사이에 PC의 새 저장이 끼어들 수 있다. 지우기가 필드 값을 확인하지 않는다.

## 다음 단계
지우기 전에 같은 PC의 값을 다시 읽어 여전히 오래된 값일 때만 지우거나, 값을 비교해서 지우는 Redis 명령으로 바꾼다. 개인용 규모에서 실제로 보이는지부터 확인한다.
