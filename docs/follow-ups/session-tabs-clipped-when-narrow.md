# 좁은 화면에서 세션 탭 줄이 잘림

## 증상
세션 탭이 두 줄을 넘으면, 브라우저 너비가 좁을 때(약 567px) 둘째 줄 아래 탭이 잘려 보이지 않고 누를 수도 없다.

## 증거
2026-10-22 런타임 확인 중 세션 탭이 13개일 때 `verify-b`, `verify-c` 탭이 잘렸고, 너비를 1400px로 넓히자 보이고 눌렸다.

## 추정 원인
`features/office-activity/office-view.tsx`의 `TabsList`에 `h-auto flex-wrap`을 주었지만, `components/ui/tabs.tsx`의 탭 목록 스타일이 높이나 넘침을 제한하는 것으로 보인다. 확인하지 않았다.

## 다음 단계
좁은 너비에서 세션을 여러 개 연결해 재현하고, 탭 목록이 줄바꿈된 만큼 높이를 갖도록 고친다. 끝난 세션 탭을 정리하는 방식도 함께 정한다.
